## Как стать программистом
### Финальный проект модуля 3

## Технологии
* JUnit 4.13.2
* Maven 3.3.2
* Jakarta 3.0.0
* Jakarta Servlet-API 6.0.0
* Jakarta.Servlet.JSP.JSTL-API 3.0.0
* Lombok 

В процессе выполнения программы задаются разные вопросы по сценариям.

Сценарии: 
1. Скучно?
   a.  Очень устал, хочу нового -> Переход на сценарий 2
   b.  У меня все отлично -> Переход на сценарий с проигрышем
2. Нужно учиться каждый день минимум два часа. Готов?
   a.  Могу попробовать и 3 -> Переход на сценарий 3  
   b. Два часа слишком много, лучше на диване с пивом -> Переход на страницу с проигрышем
3. Нужно купить подписку на Java Rush. Есть деньги?
   a. Найду -> Переход на страницу 4 
   b. Не, пойду в автоматы поиграю -> Переход на сценарий проигрышем
4. Пройти все квесты на Java Rush?
   a. Вперед -> Переход на сценарий c Победой
   b. Нет, времени же нет -> Переход на страницу проигрышем
